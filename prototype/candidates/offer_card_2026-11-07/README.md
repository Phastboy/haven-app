# Offer card reference — 2026-11-07

Owner-selected single-card composition, refined to 13px medium provider text.
The original Stitch HTML, PNG and DESIGN.md are preserved as reference exports.
Generic rules in DESIGN.md do not override the owner's rules below.

Native card: square cover, 12dp corners, save heart, no decorative border/shadow.
Exactly three single-line text rows: title; price plus optional distance; provider.
Never wrap or shrink text. Price has priority; distance gets remaining width and
ellipsizes first. Exceptionally long prices ellipsize too. Full values are on detail.
Distance is shown only with explicit active proximity and valid server distance.
Use Haven light/dark tokens and preserve server price_display and confirmed saves.
